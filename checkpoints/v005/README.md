## 恢复工程

1. 下载本目录 3 个 `seaside-castle-v005.zip.part00*` 分片和 `restore_checkpoint.py`。
2. 运行 `python3 restore_checkpoint.py`，核验分片、完整ZIP和内部载荷，解压到 `restored/`。
3. 用Blender 5.2.2 LTS打开 `restored/海边巨塔城堡_v005_双塔石砌校准.blend`。

ZIP保留34项成果和原MANIFEST.json/SHA256SUMS.txt，共36文件。模型字节原样保存；分片没有降低精度。其他脚本、预览和报告在目录中展开以便浏览。
