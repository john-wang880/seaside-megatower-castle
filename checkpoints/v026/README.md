## 精确范围与共享源保护
可见对象 `V005 | main tower calibrated stone surface` 的原720顶点/413面网格与隐藏V004来源共享。直接给原共享网格加权重会污染隐藏源，因此只为可见V005建立逐项相同的独立网格副本，再增加16个专用权重和Mask，保留其余401面精确不变。旧共享网格、隐藏对象、原材质图和全部非目标数据保持。

这是明确的数据连接变化：可见对象data指针改到专用副本，原共享网格users从2变1。不是“整个依赖图完全不变”。完整原生回退测试恢复旧data指针、移除新增组/Mask和新增对象，并验证users回到2；仅关闭Mask的LOW模式只能证明原几何观感恢复。日常回退建议从固定Git历史恢复完整v025，不单独切换半套对象。

两个真实闭合盒体的原顶点范围0…7及16…23，被一个20顶点、14多边形、36三角面的并集替代。二者西面重复面积1587、顶面重复115平方场景单位；小盒仍有690立方场景单位伸出大盒，所以不能简单删除它或用总包围盒替换。实际对象级覆盖材质 `V005 | main large ashlar calibrated world units` 原样复用，而不是误用原网格的深色基础槽；世界位置/法线映射和阴影层次保留。

## 重要：更正v024/v025旧邻接保证
此前两版的“未发现邻接正面积共面接触”依据不充分：Blender BVH.overlap会漏掉完全共面的三角形。**这项零邻接保证已撤回**，原报告/脚本不改写，另附[更正通知与可重跑审查](audits/coplanar_method/README.md)。

新方法确实找到既有接触，所有接触三角形均可追溯到原占据边界，邻居保持；没有发现并集扩大。有限原机位射线有v024的2个、v025的53个同向接触采样到达首表面，不能称全部埋藏，也不能把采样数或两两面积当可见像素面积。按现有全图复审，残余表现仍可合理读作檐台/凹部阴影，目前没有另做几何修正的充分实际收益。它们如实列为后续特定使用视角下的待观察关系，不自动扩大本版范围。

原来可靠的完整占据边界、原状态和实际前后图证明仍独立成立；不因邻接检测缺陷把整个模型称为无效。此处也不承诺全城无交叠、承重安全或全路线可达。数值为作者场景坐标，未统一校准为现实米制。
