# v012 — 入口至北侧有顶露台的真实通路

从东入口增加 L 形石砌走廊及20级台阶，到达**现有北侧有顶露台**（标高32.625），不是开放天井，也不是全城堡内院完成版。

## 变化
- 局部清空既有基础、灰石基座、檐台及局部埋藏旧构件；每个闭合实体分别处理，原始对象完整隐藏保留。
- 石地板、侧墙、顶棚饰面及露台护墙构成真实空间；不是在实体内部摆放假台阶。20级台阶升高0.18125、踏面0.6、净宽1.9；场景为米制、尺度1。
- 两扇木门向外打开90°，下缘保留0.028以上的踏面帽石间隙；原关闭门状态保留。
- 为避免局部布尔修改导致整个立面倒角半径变化，先在副本烘焙**原始求值倒角**，再局部开口；原对象仍可编辑。没有重新平滑或改动巨塔轮廓。

## 已拒绝并修正的原型问题
发现并修复了平台末端0.15间隙/倒角缺口、重叠切面黑条、门叶与帽石相交、60°门叶占用旧入口边缘，以及全局倒角收缩。仅最终验证对应的模型是本检查点，不将早期原型图片或失败报告当成通过证据。

下一步：检查基础与岩体接触、露台边缘及海岸局部表现；不机械重复铺满塔身石肋，不把这条有限通路扩大为整个城堡可导航的宣称。

基础接触补查：168个主基座周边采样全部嵌入连续岩地0.755–1.200，未发现正间隙，不依赖零散装饰岩片。因此不为制造版本而添加多余扶壁；后续另查海岸接触。这是离散几何证据，不是承载力认证。

海岸补查未发现可据此修补的缺陷：主岩地256个边界顶点低于实际波纹水面0.395–0.542；西岸实体延伸至−6.5；755个岩片组件经保守地形/水面接触筛查未发现整体悬浮。风吹浪沫的独立几何不单独视为缺陷。保留现状，避免无依据加块或压平。这不是物理仿真或全景视觉认证。
