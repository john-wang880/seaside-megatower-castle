## 三阶段

1. `build.py`：从e717与明确修正后的计划生成23个原始新件；拱石/托石前表面−71.48，背面−71.17，原场景不动。
2. `union_springers.py`：只对两对新起拱石/托石做平面YZ并集。报告原边参数区间、面积恒等式、实际交叠体积和闭合正体积；得到21个主要组件。
3. `clip_coping_embed.py`：仅从新压顶扣除实际原侧墙XZ截面，去掉重复外露侧面。保留原已存在外包络中的两个微小端部楔块，分别闭合、由原侧墙端面支承；最终23组件=21主要件+2技术保留楔块。不焊接非流形共边，不删除外露原体积。

后两阶段读取**本次**上一步报告的SHA并核对文件，以运行时哈希串联；不要求历史0dd/987候选字节。计划中的旧候选SHA仅是来源说明，不作为模型文件依赖。所有源网格/材质保持检查和几何证据随各阶段报告输出。
