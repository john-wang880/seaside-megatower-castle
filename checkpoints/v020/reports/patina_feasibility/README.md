# Closed read-only architectural patina study

After v020, one sunlit lower architectural bay was inspected under original lighting. Actual geometry showed a continuous ledge with no joints/outlets and equal shelter on neighboring bays. The existing warm ashlar, projecting stones and true buttress/coping shadows already provide coherent near-scale variation. Owner and independent art director rejected creating an isolated grime patch; no material candidate or source modification occurred.

`baseline_image.png` is actual unchanged v020 geometry/lighting, not an after image. Source/receipt hashes are in DECISION.json. FEASIBILITY records the preliminary possibility and subsequent negative artistic decision; it is not an implementation instruction. Do not invent drip paths or widen the effect to all bays merely to rescue the idea.

Local paths in historical records describe executed provenance, not required runtime files. This archive records one closed artistic feasibility study, not a repaired defect or a new model version.
