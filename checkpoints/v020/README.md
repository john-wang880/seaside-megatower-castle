# v020：西侧入口石作门槛

在v019基础上，为西侧入口补上完整、克制的分块石拱，以及两段短侧墙压顶接缝。**这是局部工艺层次丰富，不是把原入口判定为错误，也不是整座城堡重做。** 原开口、台阶、树木、材质、灯光和主体轮廓保留。

模型SHA256：`673dbbadca22d3dd45dc2f2eb5bde4a9e66851c1ca137da5c2570efc67c77614`，47,597,255字节；比v019增加6,078字节。来源v019为`e71778349c4c65eafbda3eb0a3d0753cd11e1b368a3456c4de1db2f4c0f8647a`，固定历史提交`15ed444cf3d1396d1d16e8fe5c176f8e39082435`。

## 实际观感

原光照的接近视角、斜侧近景和整体全景已审阅。完整石拱在正常接近画面可读，与原水平檐带形成明确交接；没有换成明亮描边。压顶接缝是安静的小尺度细节，仅保留入口旁两段短区间，不扩展为整条阶梯条纹。[实际斜侧前后图](previews/oblique_pair_contact.png)、[接近前后图](previews/approach_pair.png)和[当前全景](previews/hero_after.png)在`previews/`；它们不是补光诊断图。

## 恢复

从完整仓库根目录运行：
```sh
python checkpoints/v020/restore_checkpoint.py
```
输出`checkpoints/v020/restored/castle_v020.blend`，使用兼容Blender5.2.3LTS打开。逐块和整文件校验，恢复精确字节。当前保存的是经过审阅的673模型，不是重新生成后仅外观相似的替代文件。

## 几何与验证边界

- 13块拱石（两端已与小托石合并）及8块主要压顶；另保留2个微小闭合端部楔块，合计23个闭合、定向、正体积组件。楔块不是漏删碎片：它们保留原试作的外包络并由原侧墙端面支承。
- 原有24段开口折线保持；新拱环不侵入开口。两段压顶保留原侧墙横向范围；已验证中央西侧接近通道的明确范围，不宣称整座城堡通行或无障碍。
- 五处上部拱石与既有水平檐带是明确设计的次级座接，不是把所有碰撞统一忽略。原檐带与主墙接触独立验证。
- 两对新起拱石/托石做平面并集，移除重复外露面；压顶只扣除与实际原侧墙重合的区域，原墙不改。
- 数值残差如实保留：压顶共同平面最大偏差约0.888微米；两处侧面残余面积约7.61×10⁻⁸平方米，在预先界定的局部float32精度范围内，不声称无限精度数学零。
- 所有既有场景数据、材质、光照和森林保护检查；7个邻近组件/55项其他接触检查、4项故障负例。仅几何连接检查，不是受力、防水或建筑安全认证。
