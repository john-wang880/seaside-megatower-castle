# v021：消除中央桥墩的重叠表面黑缝

实际近景中的长黑缝和分叉状黑脚，并不是桥墩缺了一块：两对既有实体盒子有重复、同向的共面表面。此版仅将每对可见表面替换成其**精确实体并集**，去除渲染伪影。**没有填洞、加柱、加宽桥墩或改变拱洞与通行空间，也不宣称结构工程修复。**

模型SHA256：`457348497ba7dade666a909c029f6641a0945012f264fe088b8f06513a937ae9`，47,600,146字节；比v020增加2,891字节。来源v020：`673dbbadca22d3dd45dc2f2eb5bde4a9e66851c1ca137da5c2570efc67c77614`，固定历史提交`23fd4aaaceb64996913bfa3ff4109fc149737b9d`。

## 改动很窄，原始数据保留

- 两个原对象各增加一个明确的16顶点组和反向Mask，隐藏原来四个重叠盒子的可见表面；原顶点和面仍存放在原对象中。
- 新增两个8顶点/6面闭合并集盒子，沿用各自原材质的世界坐标映射。既有森林、v019树冠权重、v020入口石拱和其他场景数据不变。
- 精确有理数计算验证每对旧盒子的占据集合等于对应新盒子；不是用近似体积数字替代轮廓/开口保护。
- 只处理中央两对重复表面。右侧暗线是不同的侧面阴影，拱尖小暗点不在此修复范围。

### 在自己的副本中恢复原始对照

这不是通用撤销按钮或性能LOD。建议另存自己的浏览副本，勿覆盖验收文件。对象/集合名保留构建时的candidate/UNACCEPTED标签以避免为改名重新保存；验收收据记录实际状态。

原始状态、所有域的求值属性、非目标几何/材质以及反复配对回退经过独立验证。五类故障负例正确拒绝：扩大盒子、反转面、错误材质、额外Mask权重、无关森林顶点改动。
