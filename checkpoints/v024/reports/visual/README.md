# 实际画面与原样合成

背面来自同一 north/rear 相机、原始世界/灯光/曝光、80 采样、1200×866；仅相机/输出和8线程诊断运行配置，不保存场景。前后原图在 ../../previews/，收据绑定精确模型/脚本/相机与图像哈希。

rear_pair_bilingual.png 将两张原图逐像素贴到标签画布，没有缩放、补光、颜色调整或生成式重绘。compose_pair.py 是实际执行的来源记录，保留当时工作目录路径；公开原图可直接用于复核，不把该记录误作无参数通用入口。

负责人、父任务与独立艺术审阅接受六个阶梯体的局部效果，其他四组/20构件明确未处理。正面图的数值差异见 hero_comparison.json，不夸称像素完全相同。全部显示为高位检查机位，不是行人路线影片。
