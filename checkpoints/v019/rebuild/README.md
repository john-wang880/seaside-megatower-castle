# v019 自包含重建控制器（不产生新验收版本）

要求：现有Linux Blender **5.2.3**、标准Python3，恢复好的精确v018基线及已验收v019模型。不下载、不安装、不访问网络、不自动发布，也不声称支持Windows。控制器不渲染。

```
python rebuild.py --baseline '/path with spaces/v018.blend' \
  --accepted-model '/path/v019.blend' \
  --blender '/existing/blender-5.2.3-linux-x64/blender' \
  --output-dir '/new/path/rebuild result' --dry-run
```

`--dry-run`只读输入与本工具包、验证固定模型SHA并输出计划；不创建目录、不启动Blender。去掉该选项才执行，输出目录必须不存在。恢复输入步骤由已有检查点恢复工具完成，不由本控制器抓取文件。

固定v018 SHA：`c46b581a759c1b6d494fb3b31e9a7c42f749b6dfbdde1c00befbfebd9ef44cfd`；固定验收v019 SHA：`e71778349c4c65eafbda3eb0a3d0753cd11e1b368a3456c4de1db2f4c0f8647a`。

## 顺序与失败处理

1. 用历史v018生成两对象独立树与**新生成**的接触映射；无旧工作目录或641历史独立树依赖。
生成映射必须与随包的已验收公开映射gzip解压后JSON语义完全相等，允许序列化空白不同；gzip本身也纳入代码/数据哈希。
2. 以验收v019作为checkpoint运行完整保护验证，确认生成网格/材质语义与验收模型一致；不是仅比较数量。
3. 将生成树整合到基线的另一个新输出文件，不改变两个输入。
4. 对整合结果执行完整原场景/非目标保护验证、几何接触/已知路线检查、3199木管严格交叉检查。

每步独立Blender进程，`--disable-autoexec --python-exit-code 1`，参数列表直接传递，不拼接shell命令。返回码非零、缺失JSON、失败字段、折叠组件或代码/输入哈希改变都会停止后续步骤。失败保留诊断目录及`receipt.json`，不得在同一目录重试覆盖；排查后选择新目录。

开始/每步/结束核对输入模型、Blender可执行文件及工具包代码/数据哈希。输出`logs/`、`reports/`和总收据。Blender版本检查为精确5.2.3，二进制SHA记录但不下载或预设本地安装路径。

保存后的.blend字节可能因元数据不同而不同；通过的是固定已验收模型约束下的语义再现，不是创建新艺术版本、替代原e717归档或重新证明原画面。开放背面针叶、旧主干截面包络代理、仅已知路线范围等限制继续适用。
