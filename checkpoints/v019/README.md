## 可逆低细节显示（同时执行两步）

1. 在`V010 | woodland boughs with gate exit clearance`上，关闭`V019 candidate | original foliage rollback mask`修改器的**视口与渲染**开关。不要删网格/组，不要仅隐藏原森林对象。
2. 同时将`V019 candidate | articulated conifer foliage`与`V019 candidate | connected conifer boughs`两个新增对象设置为视口及渲染隐藏。

这样恢复原先叶簇，保留原木干。回到精细显示时，同步重新启用Mask并显示两个新增对象。建议另存自己的浏览副本，勿覆盖已校验模型。没有自动执行脚本或附加LOD修改器。

重复整合的保存字节因Blender保存元数据而不同，但持久数据/求值状态语义一致，见`reports/repeat/`。这不代替发布时对验收模型精确SHA的恢复校验。
