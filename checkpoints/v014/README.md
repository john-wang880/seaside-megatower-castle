新增明确标记的向下终点检查视角，按真实地面x3.85…5.05、y58…60.5投影采样：平均显示亮度约17.65→18.77，近处改善较多、最远端变化很小。30个中央终点地面点与导向灯间直接几何视线无遮挡，但这不是体积衰减/照度认证。**上阶改善清楚，终点地面只有小幅收益，远端房间仍暗。停止继续堆灯或追逐孤立亮度数值。**
