# v015 — 开启门叶的四组静态铰接支撑

修正一个有测量依据的构造遗漏：v012开启门叶与原石门框之间有6厘米间隙，原横带又在转轴前15厘米结束，没有连接件。本版添加四组克制的锻铁铰接外形，每扇门上下各一组；不改变门叶位置、轮廓、旧横带、原材质或任何灯光。

## 实际变化
- 每组包含弯折连接颈、套筒、承托销座、嵌墙锚片与销帽，共20个闭合网格对象；复用v013已有锻铁材质，没有新材质或光源。
- 原门轴位置x−3.55、y35.9/40.1保持不变，连接中心高度29.69与30.59。
- 原“Pine bark”只是均匀深棕材质，并非树皮纹理，未因名称误改。旧横带虽采用石砌节点，实际阴影视角无法可靠判断外观，本版也没有借机重做材质。
- 这是静态模型的几何连接，不是可运动铰链机构、施工图或承载能力认证。

## 验证
- 28处真实闭合体正体积交集，证明旧横带/门叶→连接颈→套筒→销座→锚片→原石门框的连接链。20个新增部件均闭合、正体积、可见；缺失/移离锚片的负控制均被拒绝。
- 初版两处下连接颈与旧栏墙穿插，被独立检查检出；外缘收回1.5厘米后，保留横带搭接并与栏墙分离。最终无非预期局部交集、无不确定开放体结果。失败证据保留，不扩大豁免。
- 原对象、网格属性/拓扑、材质节点、变换、相机、世界与全部灯光深度语义不变；重复构建一致。新增构件均在旧y36…40通路带外。
- 中央路线24静态体、624地面/1872占用采样、支撑三角形并集、旧接近路线、主桥和门叶建筑交集回归通过。沿用既有范围，**不是全城堡可导航、全宽动态人体扫掠或结构安全认证**。
- 标准Python分块恢复及10项存储测试通过；远端新鲜恢复须在发布后再次验证，再撤下旧当前载荷。
