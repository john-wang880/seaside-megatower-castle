# v013 — 真实内廊灯笼与可读性

v012已打通的入口—北转角—台阶在原照明下几乎不可辨识；不以诊断补光冒充最终效果。本版增加4具实体铁制壁灯笼及局部暖色实际光源，让进入后的通路可读。

## 模型与边界
- 4具灯笼共40个闭合正体积网格、4个点光源、2个新材质；灯功率42/36/34/40，位置分别位于入口厅、转角、北廊、台阶侧壁。
- 保留全部来源几何、材质、对象变换、原灯光、世界、太阳、曝光和相机；**最终局部照明确实改变**，不再宣称整场景照明完全相同。没有增加天空补光或改造立面。
- 窄灯笼避开既有中央1.2宽通路体；48处接缝/壁板采用精确实体交集检查，支臂实际连接灯罩，壁板嵌入既有侧墙。早期支臂未触及灯罩的原型被该检查检出4处零交集，已拒绝并修正。
- 可见的小发光焰体配合同位置点光源；焰体关闭阴影可见性，避免把配对光源自身遮死，铁笼仍投真实阴影。这是渲染近似，不是燃烧/玻璃光学仿真。
- 仍只通往现有北侧有顶露台，不是全城堡导航、无障碍或工程结构认证。

## 恢复
克隆整个仓库（包括model_chunks），运行：
```
python checkpoints/v013/restore_checkpoint.py
```
Blender5.2.3LTS打开生成文件。34,879,787字节，SHA256：
`954a9874826f6c5b54229551a25300f0967387019c9849cc6b310facb29fc2e4`

重建需要历史v012源模型，可从提交 `2545718b99b05cf2876f2b25fae031a3461ca8b2` 恢复：
```
blender -b --disable-autoexec <v012.blend> --python checkpoints/v013/scripts/refine_v013.py -- --output <新文件.blend> --report <报告.json>
```
不覆盖来源。焰体球面将面循环和面序规范化，消除Blender球体生成时的拓扑排序不稳定；所有166网格、139可见求值网格深度重复构建一致。文件字节可能随保存而不同，归档恢复则保持精确原字节。

## 通路检查增强
v012独立复查确认24个中央通路体相接；用求值三角形投影并集检查中央地板和20个台阶立面的完整覆盖，20微米容差内未发现间隙。旧台阶接触例外仅凭对象名称/区域，可能放过合成的高墙侵入；v013改为检查实际预期踏步边界平面及高度范围，并加入反例回归，14项测试通过。

这是静态、随台阶升高的中央空间体；624地面点、1872占用点与24体检查不等于动态全身扫掠或整条1.9宽度认证。旧接近路线789点、主桥765点仍为离散回归。原始数据保留、灯具连接、门叶相交和重复构建报告分别提供，不用向上净空射线替代实体占用。

`previews/v013_east_portal.png`、`v013_bend.png`、`v013_hero.png` 均为实际新场景照明，无诊断光。旧版原照明近景也保留以供比较。
