# v007 · 西桥头真实通路

阶段成果，不是最终成品。Blender 5.2.3 LTS 实际重开、建模和渲染。

## 本轮变化

- 在西桥头实心塔座和相邻承托拱内开出沿桥轴线的真实拱形通道，保留两侧实体墙及上部结构。
- 增加连续石质门槛与东侧 13 块拱券石。
- 清理一棵原本穿入实心塔座的完整针叶树：205 个树干/枝条面及 666 个针叶面。其余树林保留；所有源网格仍在工程中隐藏备份。
- 原始 75 网格、64 材质、对象变换、相机、光照、世界及曝光保持；只新增替代对象和局部构件。

## 验证与范围

- 工程重开、原始数据保留及同源重复构建检查通过。
- 3 组横向位置 × 3 组高度，共 9 条完整场景射线确认通道无阻挡。它是离散采样，不是完整导航网格/碰撞体认证。
- 新建筑网格零开放边、零非流形边。树林沿用既有叶片拓扑，不把叶片当闭合实体。
- before_portal / v007_portal 为相同镜头、光照、曝光及 16 样本的 Cycles CPU 实渲，无补画。
- **西侧地形至门槛的进阶台阶，以及东端桥面与城堡平台的高差尚未完成。本轮不宣称整条路径可通行。**

## 恢复

下载本目录 MANIFEST.json、restore_checkpoint.py 和全部 castle-v007.zip.part* 文件，运行：

```
python restore_checkpoint.py
```

脚本校验每个分片、完整 ZIP 及模型后恢复到 restored/castle_v007.blend。使用 Blender 5.2.3 LTS（或兼容版本），关闭自动执行后打开。

重建从 Git 历史中的 v006 校验模型开始，运行 scripts/refine_v007.py。输入与输出必须不同；脚本拒绝从已加工的 v007 叠加构建。检查脚本及报告均在 scripts/、reports/。
