## 恢复工程

1. 下载本目录的三个 `seaside-castle-v002.zip.part00*` 分片和 `restore_checkpoint.py`。
2. 在本目录运行 `python3 restore_checkpoint.py`。脚本核对分片、完整 ZIP 和解包文件的 SHA-256，然后解压到 `restored/`。
3. 用 Blender 5.2.2 LTS 打开 `restored/海边巨塔城堡_v002_塔冠与岩岸.blend`。

ZIP 包含封存目录的 24 项成果，以及原 SHA256SUMS.txt 和 MANIFEST.json，共 26 件文件。模型原字节完整保留；分片没有降低细节。目录中额外展开了预览、脚本和阶段文档，方便浏览；模型位于 ZIP 内。

`PAYLOAD_SHA256SUMS.txt` 是解包后载荷校验表。此目录的 `SHA256SUMS.txt` 用于校验仓库内展示和分片文件。
