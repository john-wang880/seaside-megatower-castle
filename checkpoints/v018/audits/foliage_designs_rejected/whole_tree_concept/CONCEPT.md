# Reference-informed whole-tree concept (unaccepted)

The previous dense-lobe experiment is rejected. Its individual legacy-clump envelopes were an implementation choice, not a user requirement. No further tuning of that construction is planned.

Viewed local reference-only spruce silhouette and Yale seasonal tree photographs supplied by parent. Borrow only general structure: tapered crown, radial outward/upturned main branches, downward secondary fringe, asymmetry between tiers and an opaque central mass. Do not trace the reference image, claim botanical identification or publish the copyrighted reference files.

Proposed asset language: a dense continuous tapered interior with approximately eight staggered tiers of broad **closed wedge/fan masses** attached along the existing tree's woody branches. Fan tops rise gently toward outer tips; their thick undersides form shallow down-hanging lobes, not needle tubes or ladders. Tier edges create horizontal/outward rhythm. Keep the scene's tall narrow crown proportions and original Fir/Cypress/Sunlit palette; much denser than the botanical silhouette. Existing individual pear envelopes no longer constrain the shape; original whole-tree bbox/footprint, overall height and route clearance still do.

First gate is only an isolated-tree geometry concept: orthographic front/side silhouettes plus neutral-light oblique actual geometry. These are explicitly diagnostic, not relit full-scene acceptance. Original trunk/branch context shown. No full-scene rerender, saved candidate model or checkpoint until parent reviews the concept. Render source loaded read-only with autoexec disabled; no canonical save, Git writes or external dependencies. Geometry may be retained as a local JSON recipe for review.

Success: readable dense radial bough tiers without dominant vertical pears, strong central canopy mass and asymmetric perimeter gaps. Fail: flat stacking disks, cut-paper spokes, sparse ladders, pinecone/ruffled pear outlines, or noisy needle detail. One coherent concept, no parameter loops. Whole-crown union/contact/projection and original-scene checks follow only if concept is worth pursuing.
