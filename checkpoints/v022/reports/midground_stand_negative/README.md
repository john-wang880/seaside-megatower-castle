# 三株中景树冠：有界试验否决，v022工程不变

对西塔下、路径上坡一侧的三株现有树做了只读定位。它们原有1009顶点/1558三角面，已经有两株深色窄冠与一株较亮宽冠的差异。原接近入口机位背向这三株，因此另外使用一个明确标为高位检查的真实相机，没有冒充行走视角。

实际原光照上下文图确认梨形/菱形叶团重复较明显，允许尝试一次预算不超过6000总三角面的风格化树冠团块。单次方案3624三角面，但隔离预览呈现厚重多边形层架与明显间隙，未达到饱满、相容的松柏枝冠语言。作者与工程负责人均否决，**没有整场景导入、没有生成v023，也没有再加密针叶或进行参数循环。**

原执行脚本含当时工作区路径，是审查来源记录，**不是可直接运行的便携工具**，没有为被否决方案额外开发重建产品。隔离资产只在包络拟合前做了闭合/正体积检查；最终独立几何、接触、路径和整场景比较均未进行，不包装为技术验收通过。
