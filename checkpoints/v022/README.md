# v022：西塔最低高身层的一根完整石肋

只给西塔最低高身层、面向相机的外侧一根石肋补足细致的石作分段。**这是近景工艺完善，不是发现结构缺陷，也不是整塔重新铺砌。**同一实际机位下，细接缝能读出石块尺度，仍以原有竖向框架和尖拱窗为主，不加深接缝来强行提高存在感。

## 改动与可逆对照

- 原构件实际跨越约88.7场景单位，不是独立层间小柱。本版只处理两条既有檐带之间约24.25场景单位，原始倾斜端面及上下延续段精确保留。
- 13块石作，约1.865场景单位一段；0.018场景单位细接缝、0.010场景单位倒角，连续内缩背衬。新增336顶点/356面、16个闭合正体积部件，沿用原有两种材质，不改共享节点图。
- 原对象保留全部原网格，只增加8个受控权重及一个反向Mask；新增一个替代网格对象/集合。没有复制整幅立面、扩大石肋、改变窗或通行空间。
- 在自己的浏览副本中，可同时关闭专用Mask并隐藏替代对象，恢复原始连续肋；反向同步操作回到分段状态。不要只切换一半。精确对象/组名见`reproduce/plan.json`。
- candidate/UNACCEPTED构建名称保留以避免为改名重存验收字节；以验收报告和模型SHA为准。

## 验证边界

原始和求值状态、旧森林/入口/桥墩权重、材质/灯光/世界、完整目标补集属性均逐项验证。原始倾斜终端与切面、连续背衬内缩、实际檐带内部接触通过；反复配对回退及五类负例检查包括额外权重、隐藏原件改动、外扩、反面和背衬断裂。

所有12条接缝各有5个内缩法向探针命中背衬。实际相机60条探针中，55条直接看到背衬，5条被原有更近的斜撑构件288遮挡；没有把任何原对象命中都当作通过。没有新部件内部严格非邻接三角交叉或新件之间同向共面正面积斑块。此类有限几何检查不等于全局流形、所有掠射角不透光、承载安全或整城可达认证。

接缝和倒角**有意去除狭窄部分材料**，不扩大原有包络；不能套用v021桥墩清理的“精确占据体积相等”结论。原桥其他墩脚的同源检查未发现值得再次修补的实际可见伪影，记录在`reports/remaining_bridge_audit/`，没有顺便做全局布尔清理。

[自包含程序复现](REPRODUCE.md)和`qa/`提供独立核查。先追加新版备份，经远端精确恢复/重验后才撤旧当前模型载荷；Git历史保留，不强推。工程只增长约11KB并不等于Git历史只增长11KB：本轮压缩内容寻址块约新增13.3MB。
