## 视角与目的的诚实边界

最初想在冻结的向下步行镜头中展示三拱节奏，但前76个真实姿态最多只显示一拱，旧目标明确否决。经单独批准，改为“可检查的3D室内建筑”：保持首帧眼位、朝向和26mm镜头，仅采用+8°自然抬头的独立检查相机，保留地面、墙、两盏灯和转角背景。历史漫游影片没有改镜头，也不被重新标成新版三拱演示。

实际检查图中两道完整浅尖拱形成后退节奏，石缝细、光色不变。原步行1/76帧另作无退化检查：转角、楼梯和灯光指引保持，仍有有限像素变化，不声称逐像素相同。外部hero实际重渲染的RGB像素与v026完全相同，仅限这个机位。

拱冠嵌入旧顶棚约0.02000046；冠部有限接触宽约0.29459。36条实际像素中心射线均命中完整旧顶棚或新拱，最黑采样点命中旧顶棚且灯心射线被拱遮挡。拱肩与原平顶间有设计上的局部空隙，不是顶棚缺面或冠部失座；有限射线不是完整渲染辐射分解。原灯光保持，不以加亮掩盖问题。
