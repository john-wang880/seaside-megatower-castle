## 1. 一间完整的主堡内部大厅——明确的新建筑功能

**为何值得考虑：** 现有外部是宏大的双塔城堡，已检查的内部体验仍主要是窄入口廊、转角、楼梯和向外眺望的露台。首廊石肋提升了现有空间，却没有把它变成主厅。新增一间有整体空间秩序的室内，比继续补局部线脚更可能产生实质体验提升。

这不是“原来漏做房间”，而是有意扩展工程的建筑功能：由大气的城堡通路进一步发展为可检查的完整主厅。**必须先明确选择这一新功能，不能把本路线图当作开洞/加房间授权。** 保留现有紧凑路线也是合理方案。

- **整体范围：** 现有主堡包络内一间有边界的室内，完整地面、墙面/洞口揭面、支承和顶棚构图；与既有入口序列的一处有意连接。不是全塔内部、新外部出口、额外房间链或家具堆叠。
- **预期收益：** 从“走过通道看城堡”增加一个有空间尺度和构图中心的主要目的地；应在自然站立视角可读，不靠极端广角或更多房间为它找理由。
- **首个停止关口：** 只读体积/宿主/依赖调查必须证明现有包络内存在可用空间和合理连接，同时保留原路线、外轮廓、窗洞、基础与来源回退。不能假设外壳内是空腔。若需要无边界挖空、破坏外墙或复杂新增路线，停止并重新选择方案。
- **预算：** 明确授权后仅一个≤2,000三角形空间草模；完整单室暂定≤20,000新增三角形，不默认引入贴图或道具。工作关口为一次体积可行性调查、一次草模、一次完整空间方案，不无限重复风格参数。
- **验收与风险：** 高风险。需要独立宿主/连接/源状态、开口边界、保护路线包络和自然视角评审；新封闭房间是否需局部灯具必须另列设计决策，不能假定旧灯足够或悄悄改全球照明。最多先选2–3个说明空间与连接的实际视角，首帧测成本后再安排最终渲染。无工程承重或全城可达认证。

## 2. 主塔一组完整下段立面——协调的石作构图，而非更多肋条补丁

**原意与证据：** V002明确希望竖向分段、窗洞深度、支承与上下层连续；V006只验收了两个短石作样段。当前大形节奏已好，因此“继续深化”的视觉收益置信度低于新主厅方向，不能把现有朴素面称为错误。

- **整体范围：** 选择现有上下檐带之间、包含四个现有尖窗的一个完整主塔正面构图，统筹既有揭面、窗台、附墙肋和上下座接头的石材尺度。准确成员数量/边界仍需当前源调查，不把历史样段位置当当前证据。
- **保留：** 所有开口、主要轮廓/比例、宏观色彩和主副塔层次；不增窗、窗花、雕塑，不全塔复制，也不把每根肋都机械切成条纹。
- **预期收益：** 一个完整建筑单元在实用近景中显得有一致建造尺度，而不是零星五块样品；整体竖向节奏仍应主导。
- **首个停止关口：** 完整区域清单必须能说明整体构图如何改善，不能只有“还有平面可加缝”。现有细节若已足够，直接关闭，不为了可见而扩大缝隙/倒角。
- **预算：** 一个可回退完整区域，暂定≤6,000新增三角形；一次整层实用视角对照和hero无退化。预算为设计上限，不是面数目标。保留现状同样有效。
- **风险：** 中等。材质尺度/对象级绑定、相邻檐台/窗边和重复图案会相互影响；容易产生“横条梯子”或只在微距可见的低价值改变。原照明下整层不能体现有意义而克制的收益即拒绝，不追加邻层救场。
