# v010 — 真正清空入口前室，修复漏检

本版修正旧版东侧末端平台落在既有实体基座内部的问题。原先“向上2.1净空射线”会漏检起点已经在实体内的情况，不能据其宣称平台完整可通行。

## 本轮变化
- 仅对既有基础的一个闭合构件作局部开口，清空东侧入口前室；通路明确止于**关闭的拱形木门**。未虚构通往内院的完整路线。
- 只降低地形3个顶点，消除东侧台阶边缘露出的绿色岩地片；不是删树叶，也没有整体压平海岸。
- 移除穿入西门远端的一棵完整树的可见副本部分；原始林木、地形和基础数据隐藏保留。
- v009的西侧9级台阶、护墙和门槛连接保留；原灯光、相机、材质均未更改。

## 恢复
下载/克隆整个仓库，保留 `model_chunks`，运行：
```
python checkpoints/v010/restore_checkpoint.py
```
输出 `checkpoints/v010/restored/castle_v010.blend`；Blender5.2.3LTS已验证。标准Python逐块与整文件校验；模型SHA256：`791c806a8638c2cf916dffdea51e21d288eaeaaf0983b964f11a0fed616e6bcf`。

## 验证范围与限制
- `reports/occupancy.json`：263处地面/踏面、789处脚与头部采样。将求值后的网格按独立实体分开，3个斜向射线奇偶结果一致才判定，避免重叠实体互相抵消。零碰撞、零不确定。
- 251处已知开放地形/路径网格按实际表面交叉检查，**不假称开放面有封闭实体内部**；未知开放候选仍判失败。
- `occupancy_positive_control_v009.json`：旧版正确检出34处实体占用、2处不确定，说明新测试能捕获旧漏检。
- `terrain.json`：23,368个地形接触采样，局部修复区净距至少0.1016；全扫描区无穿出。
- `architecture.json`：新增建筑闭合、正体积；`preservation.json`/`repeat_preservation.json`：源数据、灯光保留，重开/重复构建可见几何一致。旧东/西台阶及门洞回归通过。

这些是**离散建模检查，不是连续体通行证明或施工认证**。东侧可检查的行走范围止于 x=−3.5，之后是有意关闭的门；内院路线仍未完成。

`previews/v009_east_neutral.png` 与 `v010_east_neutral.png` 同机位前后；`v010_west_neutral.png` 展示西侧。均为真实模型的中性诊断照明，最终工程原照明未变。
