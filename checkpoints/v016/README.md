# v016 — 离岸小塔台阶承托与短平台

补齐一个此前远景不易看见的实际建模遗漏：离岸小塔的8块台阶彼此搭接，却与任何外部实体断开；离石基座至少0.984米，底下也没有岩石支撑。本版**不动原塔、原台阶、岩石、材质或灯光**，仅增加4个实体，把原楼梯与岩体/基座连接起来。

## 改了什么
- 台阶下方增加贴合岩体的石质承托，宽度略内收，第一踏板保留0.28米前伸。
- 上端增加短平台，保持原踏面6.444高度；左转末级再升0.18米，接到已有6.624高度侧平台，避开原立面竖肋。
- 4个新增闭合网格，共642顶点/638面，全部复用`West_Ashlar stone variation`。总计190个网格数据块，其中来源186个完全不改（包括森林、门铰接与内廊）；没有新材质/灯。
- 这只修复**静态承托及平台连接**。没有增加到大陆的桥，没有凿假入口；侧面装饰凹槽不是经过验证的门，不能据此声称可进入小塔或整座岛可通行。

## 证据
- 基准独立检查覆盖169个可见网格的附近候选，确认8块台阶只彼此连接，不能接到岩体或任何建筑实体。缺陷不是仅凭向下射线或照片判断。
- 19处精确闭合体正体积交集通过：全部旧台阶→承托→岩体/基座，以及新平台/末级连接。最小有效交集约0.00864立方模型单位，承托与岩体交集约11.5821。没有非预期立面/竖肋穿插；两层海水面只按流体接触记录，不算支撑。
- 独立从实际新网格底面取6,027点，用岩体真实求值三角形的三个方向奇偶检测，全部在内部；最近岩体表面距离至少约5.55厘米。向上移0.5米的负控制检出159/231点不满足条件。另有构建阶段26,325个竖直区间采样。两者均是**有界采样，不是每一处表面或工程承载认证**。
- 首个构建尝试的底面局部高于岩面，被断言拒绝，未保存模型；随后调整跨宽度下嵌剖面。独立验证又纠正了非平面多边形通用三角化差异，并只消除同一三角面的微米级重复射线命中，保留不同面近距离穿越；控制测试留存，不放宽几何精度。
- 来源深度语义保留、190网格数据/173可见求值网格的重复构建、旧路线/主桥/门铰接/门叶回归通过。原主城堡通行证据边界不扩张。
