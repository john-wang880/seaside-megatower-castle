## 为什么顶点检查不够

原路面的顶点在地形之上，但它们之间较粗的平面三角形会切进起伏的地形。对所选120个原三角形做完整投影叠分，约57.5677平方场景单位中12.7278（22.109%）被地形覆盖，最大埋入0.0842474场景单位。该比例是平面投影面积，不是画面像素比例；有限点采样曾低估最深位置。

所选范围是原网格第95至105横排之间，原面1140–1259。它不是路端，原路线继续向西塔下方延伸；V009平台也不直接与此网格相接。范围外的问题未被本轮自动修补。

## 局部、可逆的改动

- 原889顶点/1512三角面的路径网格完整保留。只增加63个内部顶点权重及一个反向Mask，恰好隐藏这120个面；另外1392个面的完整求值属性保持。
- 新增一个442顶点/800三角面的局部路面对象，按原路径与实际地形三角形的交线细分，沿用原有三种铺面/苔边材质及其区域，不复制或修改森林、入口、桥墩、石肋。
- 保留原XY线路与两端接缝高度。14个原端部顶点逐位相同；新插入交点受float32量化，测得最大边界XY偏差约0.000003764、端缝Z偏差约0.000001819场景单位，不夸称浮点误差为零。
- 侧边原本也有埋入，因此允许其Z贴地，XY轮廓不另行设计。局部Z调整约−0.085440至+0.105245；不是整体抬升一块悬空路板。

在自己的浏览副本中，同时关闭专用Mask并隐藏新增局部对象，可恢复旧表面对照；反向同步切换回修正版。不要只做一半。对象/组名见`reproduce/plan.json`；保留构建时candidate/UNACCEPTED名称以避免重存验收字节，以验收收据和模型SHA为准。

## 验证范围

独立检查使用实际保存并重新求值的800个三角形，与实际地形上表面逐面叠分。整片间隙约[0.0170174,0.0256552]，落在预定[0.016,0.030]内；没有用“所有顶点都高于地面”代替全表面证明。原闭合岸体的42个Z=−6.5底盖三角形明确排除在上表面高度场之外，156个相关顶面完整分区，并非任意忽略碰撞对象。

原材料、世界、照明、旧权重、隐藏原件及其他完整场景状态保持。反复配对回退通过。九类故障负例包含导出实际几何的埋入、悬浮、XY外扩、错材质、端缝、缺面、重复面，以及Blender内存中的额外Mask权重和隐藏原件改动；并非声称九项都运行完整Blender场景。另有五个合成叠分测试，包括“顶点全在地上但中间穿地”的反例。

材料边界的浮点残余交叠面积约0.00007763/57.5677，处于按坐标精度推导的界限内，已记录，不宣称严格零误差。原路径是开放、平面着色、法线向下的表现性路面，不是封闭路基实体；不套用闭合体积或承载认证。新最大坡度约0.452507，与当地实际地形约0.452277接近，不代表无障碍或全路线安全。
