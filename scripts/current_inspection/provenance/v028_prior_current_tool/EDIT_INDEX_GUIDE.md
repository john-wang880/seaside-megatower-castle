# 可选编辑索引：找到已接受的几何

此功能拟用于**单独导出的检查副本**，不是修改或重排原工程。需显式选择启用，打开副本后手动运行其中的 Text 才注册面板；不自动执行、不安装插件。显式导出开关为 **`--editing-index`**；省略时不加入编辑索引。它与 `--tree-mode HIGH|LOW` 独立：只启用编辑索引不会启用树木质量按钮。

## 四个选择入口

| 入口 | 选择内容 | 明确不包含 |
|---|---|---|
| 接待室局部壳体 | 1个局部房间网格 | 3个范围很大的 `outside chamber guard` 原建筑残部；它们不是房间局部零件 |
| 房间灯具构件 | 20个灯具网格，包括灯焰几何 | 房间内2个真正的 LIGHT 对象；选择构件不等于选择或修改照明 |
| 入口顶棚石肋 | 1个三道浅尖拱与墙头带网格 | 原墙、顶板及历史回退宿主 |
| 入口旁 HIGH 树 | 2个高细节树冠／枝条网格 | LOW替代形态、原森林宿主和其他树木 |

按钮只在对象模式下改变选中对象及活动对象，不移动、删除、重命名或隔离对象，不改相机、视口、材质、灯光、可见性或 Mask。仍用原有书签查看空间；这不是一键拆件或编辑模式工具。

HIGH 树在 LOW 模式或实际隐藏、不可选时应拒绝选择，**不会自动取消隐藏**。对象缺失、身份不符、所在层／父集合不可见或处于编辑模式时也应拒绝；不能靠强行取消隐藏、切换模式来绕过检查。四种导出与独立检查已在 Blender 5.2.3 Linux 完成：13 类原始状态保持、18 个书签、27 个既有质量负例及 37 个选择负例通过；这不代表 Windows 桌面点击已验证。

## 选择之后仍需注意

- 单用户网格不等于独享材质。石材、树木、金属等节点图仍可能被其他对象共享；改一个共享材质可能同时改变其他建筑或植被。
- 灯具是装配构件。20个网格按钮排除了两盏实际灯光，单独移动灯罩／灯焰或删除支座会破坏已验证的相对位置与连接。
- 房间局部壳体与原建筑、门洞和保留实体共同组成空间；“可以选中”不表示可以独立搬走、删除或任意改尺寸。
- 不要用全局取消隐藏、关闭版本 Mask 或隔离整集合当作回退。旧源与新替代件可能同时出现，产生重复表面；原有多版本修改器顺序、权重和隐藏状态都需保留。
- 此索引不提供结构安全、完整通达或独立编辑安全认证。重要修改先另存工作副本，并重新验证相关几何、材质及照明。

## 为什么还有 UNACCEPTED / candidate 名称？

当前已接受工程中的 **5个 v019–v023 集合**保留了历史 `UNACCEPTED` 名称，部分对象也保留 `candidate`。这些特定名称是历史标识，**不是说它们仍是被拒绝的试验**，也不能据名称推断其他对象已接受。新面板提供清晰的功能入口，不给原工程自动改名，以免破坏名称绑定、恢复链或既有测试。

原模型仍是已验证的 v028；检查副本中的派生标记仅说明创建来源，不为日后用户编辑作质量担保。原生 Windows 和桌面点击尚未在此项工作中验证；命令见本说明与 `EDIT_INDEX_REPLAY.md`；当前模型保持 v028，不新增模型版本。

## 明确的操作界限

面板只提供选择入口，昂贵的目标身份检查发生在按钮操作前后，不代表对用户后来改动的共享材质节点图作认证。改动顶点、拓扑、变换、目标材质绑定等造成索引过期时应重新导出原始检查副本，不要强行绕过守卫。

不同启用配置的检查副本共用受保护的注册命名空间。在同一 Blender 进程切换副本时，如遇注册身份冲突，请先卸载原副本自己的面板或重启 Blender；不要启用全局自动脚本执行或强制删除其他注册类。

### 手动修改后的范围限制

索引用于原始派生副本中的查找和导航，不是编辑后的持续认证工具。手动改变几何、拓扑、变换或目标绑定后，严格指纹可能拒绝继续选择；不应降低检查绕过它。

**重新导出不迁移、不覆盖也不丢弃你的编辑。** 请先把编辑成果另存为独立工作文件。新的原始检查副本仅恢复受保护的导航状态，不会把修改合并进来；原索引不能为编辑后的模型作认证。界面名称中的“编辑索引”只表示帮助找到对象，绝非不受限制的编辑或编辑后验证工具。

当前面板还检查副本来源与启用状态：切换到无标记或不匹配的场景时只显示错误，不继续展示已接受几何按钮。此检查不逐帧计算网格指纹；点击按钮时才进行完整目标检查。独立 QA 另覆盖 6 个面板绘制场景。
