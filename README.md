## 实际改造

采用塔内原有约133平方米、净高4.50米的空间，替换办公式玻璃隔断和现代阅读家具，建立四道实体石肋、三跨连续拱腹、八座落地石墩及厚入口、壁龛、宴会长桌和高座。拱壳在两道原木梁处真实下收，并非把构件隐藏；原木梁、天花、上层楼板、楼梯和城堡外部保持。桌席和北侧通行画廊分开，厨房来向在厅内有实际落盘台及完整转身位置。

三扇北窗保留真实洞口和外框，窗面局部改为上分彩绘、下半清玻。新增灯具和暖光属于模型设计的一部分，原世界和海雾不改；因此前后是同机位和曝光，不是完全同照明。所有新增材料独立，不改共享的外堡材质。

## 检验与图件

源与候选的原有对象、原始及评估网格、共享材质、世界、楼板和楼梯按允许范围核对。三跨拱体、石墩真实支承、旧梁净距、完整地面和1.10米宽×2.25米高通路单独验算；旧落盘站点的真实碰触记录保留，新站在柜前完整可用。正式通过状态、负样本和独立重建结果以 `S99_VALIDATION_SUITE.json` 为准，不把前期草稿当交付。

厅轴、画廊、窗景和全景均有同机位前后图；结构剖面为独立、明确标注的选择性隔离诊断，不是实际室内视图。窗外射线可穿玻璃与体积雾到达真实海面，但这不保证雾中海面在成图里清晰；以实际画面说明，不用贴图代替海景。

## 尚未完成

这是一间完整塔厅的空间重塑，不是全堡内部全部重建。底层厨房、已有洗浴区和上层私人房间尚待按奇幻建筑风格逐区改造。送膳仍经原公共楼梯，与宾客共享；北侧上行也仍通向现有卫兵层，不声称独立后勤梯或全套私人通道。厨房真实外排烟道、水电与浴池排水尚未完成。模型为静态场景，不是工程安全认证或已可玩的游戏。
