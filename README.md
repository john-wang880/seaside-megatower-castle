# S95：入口、收货室与厨房库存的连续补给通路

基于已回读验证的 S94，父提交 `0701dd18b2a20e74b702da574bcb4b3d8d64355f`。本轮修复原有空间之间的真实断点，不新增楼层，不用小道具代替建模。

## 改善范围

旧储藏西门中心线本来可通过，真正的问题是其西侧没有接到已经验证的入口路线，东端库存货架又堵住转向厨房的通道。新增局部短支廊穿过入口与收货室之间的石体，接上既有收货通道；北侧三格货架及其货箱、斜撑整组西移 0.6 米，保留容量，为库存东端让出转弯区。路线连接入口、收货室、储藏西门、库存取物点与 S94 厨房服务廊。

固定局部切割范围为 `[5.75,35.45,28.75]..[7.25,38.12,31.55]`。原始结构对象隐藏保留，新建对应局部替代；旧货架不是删除。新廊额外核验净宽 1.36 米、灯下实际最低净高 2.460 米。验证仍要求 1.1 米完整足迹及 2.25 米头顶净空，没有缩小身体标准来通过测试。

## 限制

这仍与家庭及守卫共用入口，不是独立后勤入口。厨房炉具保持冷态；本轮补充真实炉罩位置的几何障碍审计，但没有建立外排烟道、燃烧系统、给排水或消防/结构认证。几何路线验证不等于可玩导航或实际建筑通行认证。不存在以一幅切片图代替真实未切模型检查的说法。
