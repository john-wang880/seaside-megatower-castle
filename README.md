## 设计与真实约束

在既有岛上石径旁设置通往林缘小花园的新支径。原入口存在地形和岩束约束，连续缓坡无法同时满足旧接面与限坡，因此采用明确的两级低石阶和落脚段，再接主体缓径，而不是用暗错台冒充平顺通路。花园平台顺地形缩小并向较平的西南侧调整，设置石缘护边、双座和分带草本种植。主体支径约23.50米，休憩台地约26平方米；两级入口实测约13.64/13.35厘米；主体核验带最大纵坡8.878%、横坡3.888%。45处新旧边界检查的最大可见面高差约18.59毫米，最大材料缝宽10.79毫米。

岛体、森林、建筑及原石径不切不移。仅在新铺装准确固定的投影轮廓内清除穿出路面的旧草叶；原草聚合对象隐藏保留，替代对象在授权轮廓外保留原表面及材质。这不是广域清林或隐藏地形。明确记录初稿草穿铺装、地形侵入踏槛和过高平台等被拒绝问题及修正。

## 检查范围

分别检查原路接缝、两级石阶、主体缓径、转角/端点和停留站位。通行净带要求1.1米、净空2.25米；主体新缓径纵坡不超过10%、横坡不超过4%，不把石阶混入坡路豁免。旧接口的极窄材料缝独立检查缝宽、缝底承托和两侧实际可见高差，不能把埋在地形下的旧砖当作落脚面。坡面以真实三角平面检查，另检查地基与原地形的实际相交/支承样本。不能由局部接入推断整条旧岛路直到城堡都已复验。

负样本应区分铺装不连续与地面仍能支承，不能把缺一片贴地铺装假称悬空。历史室内、楼梯、守卫、厨房、洗浴隐私等固定回归保留。

## 局限

这是静态景观模型，不是无障碍路线或真实建造、排水、侵蚀及海岸安全认证。原路线部分坡度和原场景问题并未在本轮全部修复，接入旧侧仍保留最高约30.6厘米的原软草，不称旧路已清障。局部材料缝底凹约39.87毫米，但最大缝宽约10.79毫米且有原地形支承；分别报告，不把缝底当行走面台差。草本是程序化造型，不是植物学复原或动态植被。厨房外排烟道与实际水电仍未完成。
