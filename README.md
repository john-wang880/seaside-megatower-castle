# S98：旧主径核心修复与花园衔接

基于已完整回读的 S97（父提交 `0e3d6ff6dab45a63634846b1d58ac4e669848a5f`，模型 SHA256 `4ec45c41d985dc162bfd1829abefa8eadcc8e3f43f05760681a1a8fe08366a03`）。

本轮目标是把花园附近通向林缘的旧山径做成连续、露土露草更少且有合理横断面的实质空间，不新增孤立道具。原路不是平地：最初南端候选的净带横坡约60%，与历史 S59/S62 路段相交。不能通过把草盖住就称完成，因此弃用该广域方案，改为有可行端点的核心修复段。最终范围为原第38–82环，链长66.04米。实际1.10米核验净带的最大纵坡约22.77%、横坡约3.98%；同一修复段旧路实际内带最大纵坡约28.26%、横坡约35.17%，并非采用已放弃大范围的旧数值作比较。新路纵坡依然明显，仍是山坡步道。

范围内替换旧铺面并精确裁草，原对象仍在模型中隐藏保存；范围外表面与材质双向核对。原岛体、岩石、人物、木质树体、历史室内及 S97 支径/两阶/花园不改。仅在有限高度步道净空内修剪少量低针叶，剪切体外保留原叶面和材质；原针叶聚合隐藏保存，绝不以无限高投影清冠。唯一花园接口的实际毫米级缝隙增加下凹约4毫米、有地基支承的填料，不抬旧槛。原山路的纵坡不可与 S97 较缓的新支径混称，也不称无障碍或施工认证。

## 验证与真实限制

检查保存后实际可见三角面的净带、铺面连续、坡度、地形/草叶穿出、基底支承和端点/花园接缝；不能把旧隐藏网格当作新可见路面。历史回归明确把退休旧主路接口映射至新主路实面，其余 S97 新建空间与更早生活空间保留检查。

南侧旧陡草甸与两条历史支路仍需单独重接设计。本轮不等于全186米主路或城堡门洞全部修复。只作静态模型，不具备真实水电、排水或结构安全认证；厨房外排烟道等既有未完成事项未被本轮解决。

四组对比均使用真实场景，同机位、同光照，不隐藏树林/岩石来制造改善。三组前图直接保留 S97 原候选图与原元数据。新版仅新增核心道路视角，不把修复范围外的原路描述为已经修好。
