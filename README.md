# S102：屋主寝居、窗向书写与更衣区

以已验证 S101（GitHub `434012898b182689aaa97f29854f9044d949264d`）为基线，重整原有约 12.1×13 米屋主寝室，不新造楼层，也不把上层卫兵休息/交接房改为私室。

在四个限定施工区内，把寝台、带真实承柱的低木顶架、窗向坐席与书写面、东南更衣收纳连成可走动的生活空间。21 件旧寝室家具隐藏归档，不删历史。保留原门窗、两根承重柱、木梁、楼板、顶面与旧灯，不能把原有约 3 米层高渲染成虚假的挑高大厅。三盏新灯分别固定在两床架托座及书写台，用于实际阅读和寝台照明；配对图保持相机、曝光与采样一致，但不能称前后完全同照明。

## 实际限制
固定木屏是睡眠与坐席的分区，入口和近处通道仍存在看见床的视线，不能称完全遮挡。卧室通往浴区仍走原公共厅通路，没有新独立私梯。北窗保留原洞和玻璃，没有独立证据保证渲染中能看见海面。S101 冷灶未接室外烟道、石盆无供排水，原送膳楼梯共用的状态未改变。

## 验收与备份
新床架、台面、柜体、灯托的实体承接，完整通路净空，原结构碰撞、外露共面与源模型保全均需独立检查；分区屏视线按实际结果记录。S100 浴室双门闭合遮挡和 S101 厨房退柱设计须回归，不用本版外观图代替。

S102 是从 S100 完整基准开始的第 2 个增量。保留 S101 父提交和 S100 基准提交，逐层验证原始流、封装模型、各分片与备份清单的 SHA-256。冷恢复只使用远端 Git 对象及受信任的本地解码器，不执行归档内任意脚本，也不借用本地 S102 候选。最多连续 8 个增量后建立完整新基准；旧历史不删除。当前 512 MiB 原始流窗口若不够，必须先采用完整备份或实测新配置，不能无声放宽。
