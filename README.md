# S96：家庭层洗浴空间与厕前隐私动线

基于已完整回读验证的 S95，父提交 `4b6fdf2cd623309be74f81586e962bdb67488c8d`。本轮完善原家庭层生活空间，不新增楼层，也不假装打通外排烟道。

## 实际改造

保留家庭层原有房间壳体、门、北窗、更衣凳及通往厕室的旧路线。仅隐藏保留原五件封实的洗槽/厕座简块，不切割结构，不平移原对象。新建有真实凹腔的盥洗台、独立坐浴器皿及厕座；浴区与盥洗台之间加入不透明短屏，厕前增加半跨不透明遮挡墙，同时保留可绕行的东侧通道和使用站位。独立审计发现的浴缸走廊直视问题已用浴屏修正；厕屏西端增加由原结构地面完整支承的 8 毫米地坪收边，而非留下悬空脚。新照明属于保存模型，而非仅在预览中提亮。

新旧通路仍按 1.1 米完整足迹和 2.25 米净空检查，包含转角和端点站位。浴缸沿高约 0.554 米、凹深 0.392 米，厕座高约 0.464 米。浴缸旁站位可达不等于已验证进入浴缸，仍须跨越缸沿。隐私报告只覆盖列明观察点和目标，不是全屋所有视点的隐私保证，也不把静态屏风当关闭的门。

## 限制

水嘴、洗浴器皿和厕座均为静态模型；没有连通给排水、防水层验证、热水、外排烟道或真实施工/消防/结构认证。不是无障碍或角色动画、可玩导航验证。保留原窗不等于新增自然采光或通风性能已达标。

## 验证与图件

验证包括固定历史路线/厨房/补给通路/守卫等回归，本轮真实凹腔、支承、站位及改动白名单，另以故意堵门、移除地板、降低梁和分别去掉浴屏、厕屏的副本检验测试能识别实际问题。独立重建比较全场景几何、变换、材质与相机。
