# S100：石拱浅泡池、真实入池阶与双态隐私门

这是 S100 目标的收尾版本，不表示城堡所有设想都已完成。以完整远端回读的 S99（提交 `9af041dcde026d5ba9aa5ca1540566e15386199b`，模型 SHA `47483d39bcb68f3839bfc821b943f7f19a277f56d5804e61f60dbdc76142d0da`）为基线，保留士兵、宴会厅、原楼梯、房壳、楼板和海岛景观。

## 实质改造

在既有家庭洗浴房内，建立完整石拱壁龛、落地石墩、带正厚底的一体海青石池、实际升降踏步、短厚石手盆和布草龛。不是用新浴盆替换旧浴盆：新湿区按建筑尺度连成整体，旧的 44 件浴具及盥洗家具隐藏归档，旧更衣长凳、主走廊和北侧私厕保留。

池底不凿穿楼板。静态水最深约 20.8 厘米；实际逐级上沿、下池与池底均按完整脚宽检验，不能把水面当承重地面。原梁处保留实际净距。水只作场景表现，没有供水、排水、防水或供热系统。

## 门与隐私分状态

初始开放方案确会让外廊和共用过道看入浴区，因此增加西侧厚石屏及两扇不透明铰接门。默认保存为开启，叶片停在踏带两侧，不挡干转位；关闭时通过真实门叶遮挡，不隐藏任何其他场景对象。

在 Blender 中，将 `S100 | privacy gate west hinge pivot` 与 `S100 | privacy gate east hinge pivot` 的 Z 旋转都设为 0 即为关闭；默认开启分别为 −90°、+90°。模型包含可复现的两种姿态，不是已运行的游戏交互或动画。开门才能通行，但开门状态不能保证浴区隐私；关门状态用于检验遮挡，不声称能穿过关闭的门。北侧私厕仍保留原遮挡。

原门方案在接近全开时碰到入口回折石段，且两枚固定上销超出局部范围；已修短新石段并降低新销，失败报告保留。最终检验绑定最终模型，不能用旧候选的通过结果替代。

## 为什么未建独立送膳梯

厨房至宴会厅约 11 米高差。在保留现有层板、露台和士兵通路的本轮约束下，局部新梯会穿越四组既有结构，东侧还与值勤梯相冲。未以货梯、穿墙路线或大面积删堡体冒充解决；供膳继续共用原楼梯。独立楼梯塔或总体重规划并非永远不可行，但不属于已完成内容。
